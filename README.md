# Cloud-Native Microservices Observability Platform

## Project Overview

A hands-on Platform Engineering project that implements an
end-to-end observability platform for a Kubernetes-based
microservices application.

The platform integrates metrics collection, centralized logging,
distributed tracing, visualization, and incident alerting.

## Objectives

- Deploy a microservices application on Kubernetes.
- Implement application and infrastructure monitoring.
- Collect and visualize metrics using Prometheus and Grafana.
- Centralize application logs using Grafana Loki and Alloy.
- Implement distributed tracing using OpenTelemetry and Tempo.
- Configure operational alerts using Prometheus and Alertmanager.
- Develop incident response runbooks.
- Document deployment, validation, and troubleshooting procedures.

## Technology Stack

- Docker
- Kubernetes
- Minikube
- Helm
- Prometheus
- Grafana
- Grafana Loki
- Grafana Alloy
- Grafana Tempo
- OpenTelemetry
- Alertmanager
